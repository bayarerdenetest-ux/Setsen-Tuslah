# ЗөвЭмч: эмчийн цаг захиалгын прототип

Эмнэлэгт ирсэн үйлчлүүлэгч угтах ажилтанд хандахын оронд **киоск** эсвэл **утаснаасаа** цаг авдаг системийн прототип.

Үйлчлүүлэгч хоёр замаар цаг авна:

1. **Эмчээ мэдэж байна.** Тасаг, эмч, цагаа сонгоод шууд захиална.
2. **Зовиураа хэлье.** Шинж тэмдгээ оруулахад систем аль тасгийн аль эмч дээр очихыг санал болгож, сул цагийг шууд гаргаж өгнө.

## Боломжууд

- **Киоск горим:** том товчлуур, ЭМД карт уншуулах, талон хэвлэх (дүрслэл).
- **Утасны горим:** e-Mongolia-аар нэвтрэх, SMS сануулга (дүрслэл).
- **Ажилтны самбар:** бүх захиалга, AI-аар чиглүүлсэн хувь, киоск/утасны харьцаа.
- **Яаралтай шинж тэмдгийн шүүлтүүр:** цээж өвдөх, саажих, ухаан алдах гэх мэт шинж тэмдэг илэрвэл цаг өгөхгүй, яаралтай тусламж руу илгээнэ. Энэ хэсгийг AI биш, хатуу дүрэм шалгадаг.
- **Тасаг санал болгох:** онош тавихгүй, зөвхөн тасаг санал болгоно. Итгэлцүүр бага бол Дотрын тасаг руу (ерөнхий үзлэг) чиглүүлнэ.

## Ажиллуулах

Нэг файлтай статик хуудас. `index.html`-ийг браузераар нээхэд л ажиллана, эсвэл GitHub Pages дээр байршуулж болно.

## AI-ийн тухай

- Claude artifact дотор нээвэл зовиурыг AI загвараар шинжилнэ.
- Энгийн браузер эсвэл GitHub Pages дээр нээвэл **түлхүүр үгийн дүрмийн горимоор** ажиллана. Хариу дээр ямар горимоор гарсныг бичсэн байдаг.

Бодит системд AI дуудлагыг сервер талд (backend) хийж, API түлхүүрийг хөтөч рүү хэзээ ч илгээхгүй байх ёстой.

## Прототипийн хязгаарлалт

- Эмнэлэг, эмч нарын нэр, өрөө, хуваарь бүгд **зохиомол жишээ өгөгдөл**.
- Захиалга зөвхөн тухайн браузерын `localStorage`-д хадгалагдана. Сервер, өгөгдлийн сан байхгүй.
- Талон хэвлэх, SMS, ЭМД карт, e-Mongolia бүгд дүрслэл.

## Дараагийн алхам

- Backend (цаг, эмч, хуваарийн өгөгдлийн сан) болон эмнэлгийн мэдээллийн системтэй (HIS) холбох
- Зовиур → тасгийн дүрмийг эмч нартай хамт баталгаажуулах
- Хувь хүний мэдээлэл хамгаалах тухай хуулийн шаардлага (зөвшөөрөл, шифрлэлт)
- Нарийвчлалыг хэмжих: буруу тасагт очсон хувь, хүлээлгийн хугацаа
